# 2026 高教社杯全国大学生数学建模竞赛 C 题——微网电力调控优化

本项目为 2026 年全国大学生数学建模竞赛 C 题（微网电力调控优化）的完整求解工作，
包含全部建模与求解代码、全年评估结果、审计与消融实验数据，以及定稿论文源文件。

## 问题与模型

微网以 10 分钟为时段单位运行（每日 144 个时段），评估期为 2025-02-01 至 2025-12-31
共 334 天（1 月仅用于暖机传递储能初始状态）。储能参数：容量 12000 kWh，
SOC 范围 [1200, 10800] kWh，功率上限 5000 kW，往返效率 0.81。

| 问题 | 内容 | 模型要点 |
|---|---|---|
| 问题一 | 确定性日前调度基线 | 基于给定日前预测制定购电计划与储能调度 |
| 问题二 | 考虑光伏预测误差的购电决策 | 滚动信息修正 + CVaR 风险规避 + 紧急购电机制 |
| 问题三 | 日内多次预测更新下的计划调整 | 00/06/12/18 时发布时刻滚动修正，含发布时刻消融实验 |
| 问题四 | 波动电价环境下的风险管理 | 光伏-电价联合历史场景 + MPC 滚动控制（q4_2 / q4_3 两个子问题） |

所有问题共用同一物理约束框架，仅通过逐步扩大的信息集区分。

## 环境与复现

依赖：Python 3.8+，numpy、pandas、scipy、openpyxl。

```bash
cd C题/代码
python prepare_data.py    # 0. 预处理：生成模型输入数据
python solve_q1.py        # 问题一：确定性基线
python solve_q2.py        # 问题二：CVaR 风险调度
python solve_q3.py        # 问题三：发布时刻滚动修正
python solve_q4.py        # 问题四：联合场景风险管理（q4_2 / q4_3）
```

全年求解耗时较长（问题二至四需逐日滚动求解 334 天）。求解结果
（JSON）自动写入 `C题/结果/`，随后由导出脚本写入官方模板：

```bash
python export_results.py  # result1 / result2.xlsx
python export_q3.py       # result3 / result3_final.xlsx
python export_q4.py       # result4-2 / result4-3.xlsx
```
